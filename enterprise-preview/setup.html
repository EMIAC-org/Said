Said Enterprise

Deploy on your infrastructure. Your meetings, your data, your control.

Requirements

Docker + Docker Compose on any Linux VPS. 2 vCPU, 4 GB RAM minimum. Postgres 15+ included in the compose stack.

Step 1 · Deploy

Deploy the control plane.

One command on your VPS. The Docker image includes the meeting server, Postgres, and the admin dashboard.

Terminal

$ curl -fsSL https://get.said.dev | bash
$ cd said-enterprise
$ cp .env.example .env
$ vim .env  # set LARK_APP_ID, LARK_APP_SECRET, DOMAIN
$ docker compose up -d

Connect to Lark

Lark OAuth gives Said your org directory, task sync, and doc export — all with one login.

What we get access to

  • User identity (name, avatar, email)
  • Org directory (departments, members)
  • Lark Tasks (create, assign)
  • Lark Docs (create, write)
