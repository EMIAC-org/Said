Tier 2 — 4-pass local correction

crates/backend/src/tier2.rs :: CorrectionEngine::correct

PassFunctionApplies?Key gates
1 Exact alias stt_replacements::apply_exact_safe Yes — live review_status=approved, not common word, plausible alias, word-boundary match
2 Edit policy apply_edit_policy Yes — active rules status=active, context bigrams, common-word veto (alias_safety WIP)
3 Cluster fuzzy cluster_fuzzy_pass Yes — if targets exist Requires active edit-policy target; score ≥ 0.78; max 3/recording
4 ONNX / deterministic fuzzy_scoring_pass Shadow-only* score ≥0.86, margin ≥0.18, det_floor ≥0.68 — only applies with direct policy evidence*

* WIP on lahore-v10: Pass 4 scores always run (ONNX if model on disk, else deterministic phonetics) but applied requires has_direct_policy_evidence — prevents fuzzy auto-apply like kaisa→Macobs. Committed v2.2.0 applied pass 4 more aggressively.

correct(transcript):
  exact = apply_exact_safe(transcript, approved_stt_rules)
  edit  = apply_edit_policy(exact.text, skip_already_corrected)
  cluster = cluster_fuzzy_pass(text, active_edit_targets_only)
  fuzzy = fuzzy_scoring_pass(text, protected_tokens)
    build_candidates(approved_aliases + vocab)
    FOR EACH token:
      skip IF common_word OR alias_safety blocked OR in dictionary
      score = max(deterministic, onnx_blend)
      boost from tier2_policy weights if learned
    APPLY IF policy_score present AND margin≥0.18 AND score≥0.86 AND det≥0.68
  OUT: { text, matches[], traces[] } → recorded to tier2_decision_events

Paste + 30s edit watcher

crates/paster + main.rs :: watch_for_edit (~L4008)

Live typing (macOS)

  • paster::type_text — CGEventKeyboardSetUnicodeString
  • 6ms keydown→keyup, 6ms post-keyup (sacred)
  • Windows: SendInput KEYEVENTF_UNICODE

Fallback paste

  • pbcopy + Cmd+V via synthesized events
  • Used when live typing fails or reset sentinel fired
watch_for_edit(recording_id, polished, target_pid, pre_paste_text):
  sleep 400ms                               paste animation settle
  poll paster::read_focused_value_for_pid(target_pid)
    interval: 50ms fast → 300ms slow after 2s idle
    max duration: 30s

  IF AX returns empty (Chrome/Lark contenteditable) → RETURN (no learning)
  IF field == polished → no edit, RETURN
  IF !is_meaningful_edit(polished, user_kept) → RETURN
  IF !shares_word_overlap AND !format_transform → garbage, RETURN

  extract_kept(polished, post_paste, effective_val, pre_paste)
  POST /v1/classify-edit { recording_id, ai_output, user_kept, capture_method:"ax" }

Classify / learning pipeline

crates/backend/src/routes/classify.rs :: classify

── Early gates ──
IF !learning_enabled → no_edit
IF time_since_paste > 30s → stale
IF user_kept empty → full_deletion
IF ai_output == user_kept → no_edit (+ reward_active_terms +0.1)

── Negative signal (demotion principles) ──
run_alias_revert_pass(polish, user_kept)
  vocab term in polish but user replaced it → delete STT alias only (vocab kept)
tier2_edit_policy::mark_removed_feedback(recording_id, user_kept)
  FOR EACH applied tier2_decision_event where chosen_form NOT in user_kept:
    stt_alias → stt_replacements::demote(weight -1.5, delete at ≤0)
    other scorers → penalize_rule + tier2_policy::penalize_mapping
    WIP: also covers deterministic/onnx/policy scorers
    WIP: insert BLOCKED rule if no rule existed
  → penalized_pairs → negative_terms → status bar pill + ONNX retrain

── Positive learning ──
hunks = edit_diff::diff(transcript, ai_output, user_kept)
changes = deterministic_classify_hunks(hunks)   no LLM classifier in hot path

FOR EACH SttError change:
  skip IF common_word(corrected) OR numeric_junk
  skip IF !appears_in_user_kept(corrected)
  skip IF script mismatch (Devanagari in hinglish mode)
  alias_safety::judge_alias_source(original→corrected)   Groq 8b, cached
  IF stt_change_count ≥ 2 → review card (no auto-learn)
  IF single + (brand|acronym|code_identifier) → auto-learn
  ELSE → review card

ON auto-learn:
  vocabulary::upsert_for_language_with_context
  stt_replacements::upsert_aliases_for_language (both transcript + polish spans)
  tier2_edit_policy::record_explicit_edit (needs 2 positives to activate)
  spawn_vocab_embedding (background Gemini)
  schedule_onnx_retrain (debounced 5s)

RESPONSE → desktop:
  vocab-toast | vocab-queued | vocab-review | vocab-confirm events
