What is already correct

  • It uses the current Rust/Tauri dictation path, so quality should not regress from a Swift rewrite.
  • The HUD now visually belongs to the notch area instead of floating near the Dock.
  • The transparent canvas prevents resize clipping during state changes.

What is still approximate

  • Current placement is simply top-center; it does not yet read physical notch metrics.
  • Closed size is fixed, not derived from each MacBook model's notch width.
  • Screen changes and multi-monitor movement need deterministic repositioning rules.

Next deterministic pass

  • Detect notch width / safe area per display, then derive closed and open HUD sizes from that.
  • Lock exact y-offset and Space behavior in Rust, not only React CSS.
  • Use a state table for every size, animation duration, and hide timeout.
