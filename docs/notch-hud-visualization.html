What is already correct

  • It uses the current Rust/Tauri dictation path, so quality should not regress from a Swift rewrite.
  • Rust owns placement from native display metrics; React no longer guesses screen position.
  • The closed black surface is derived from the physical notch width and height on notch Macs.

Fallback behavior

  • External and non-notch displays get a small top floating island instead of fake notch geometry.
  • The status window is resized/repositioned from Rust when the app state syncs.
  • The larger transparent canvas prevents clipping while the black HUD expands downward.

Remaining tuning

  • Test on the actual MacBook notch screen and one external monitor.
  • If the notch has a small visual mismatch, tune only the clamp/fudge values in Rust.
  • Later choose focused-display placement instead of primary-display placement if needed.
