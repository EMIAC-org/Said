AirNote

Speak anywhere. Polish only when you choose.

AirNote types into the active app, keeps the small status pill visible, and gives you focused shortcuts for dictation, message polish, and HUD placement.

Rule of thumb: normal dictation is fast and direct. Polish Mode is for messages that should sound professional, so it intentionally waits for the final polished version and pastes once.

Voice mode
1

Turn on Polish Mode: macOS uses ⇧⌘Space; Windows uses CtrlShiftSpace.

2

Speak normally with your record key: Fn on macOS by default, or Caps Lock on Windows by default.

3

The target app receives only the final polished message. No draft text is streamed into the field.

Learning And Vocabulary

Personal

Your Mac learns locally

Edit a proper noun, brand, acronym, or code word after dictation. AirNote learns that correction on your machine.

Company

Company bucket

Enterprise users can receive approved company-wide words on day one, without rebuilding personal vocabulary from scratch.

Safety

Common words are blocked

Common Hindi, Hinglish, and English words should not become aliases for company terms.

Permissions Needed

SystemWhat AirNote needs
macOSAccessibility to type or replace text, Input Monitoring to detect global shortcuts like Fn / Option + 1 / Shift + Command + Space, and Microphone to record your voice.
WindowsMicrophone for dictation. AirNote uses the Windows keyboard hook for global shortcuts and SendInput for typing, so there is no macOS-style Accessibility or Input Monitoring grant.
